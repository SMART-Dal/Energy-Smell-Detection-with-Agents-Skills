CANNOT RUN: `collect_jobs` fetches its data by looping over `WORKFLOWS` and calling `gh_paginated`, which shells out to the `gh api` CLI (`subprocess.run(["gh", "api", "--paginate", ...])`) to reach the GitHub REST API. That needs network access, GitHub credentials and an external `gh` binary on `PATH`; no argument it accepts can avoid it (only the `since` timestamp is an input), and standing in for `gh` or patching `gh_paginated` would be faking the environment/a mock, which is not allowed.
